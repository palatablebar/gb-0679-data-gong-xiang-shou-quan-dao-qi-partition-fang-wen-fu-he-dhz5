# 授权定义

资源orders与订单等价，customers与客户等价。principal为主体文本，不支持模糊主体。partition为YYYY-MM；分区授权[start,end)不含end月。授权时间也为[start,end)，到期时刻立即失效。

每条授权包含主体、资源、生效窗、分区窗和allow/deny。全部条件必须同时匹配。拒绝优先，多个允许不能覆盖任何显式拒绝；无匹配默认拒绝。匹配规则ID按字典序稳定排序，冲突显示全部允许与拒绝证据。

observed为真实访问执行结果allowed或blocked；reported为上游0/1判定，留作证据。expected为实际授权复算，分区模块重建reported为执行结果便于二值对账。越权放行和误拦截分别计数，禁止用相互抵消的总数代替逐条核查。

业务ID和超大整数按文本保形；Decimal参与数量金额计算，对外序列化为字符串。哨兵集合定义在app/values.py，缺失值不能当零。所有时间带UTC偏移，先转UTC比较，业务日按指定地区划分。区间统一[start,end)。重复业务键保留第一条、完全相同行计重复；值冲突行隔离且保留原值。空文件、全空白、仅表头分开拒绝。

运行清单包括输入sha256、规则版本、参数、生成时刻与耗时。源行编号以CSV解析器的物理结束行号表示，引号内换行不增加记录数。输入超过4MB返回413，非法表头和类型返回422，失效版本复核返回409。

# 特征版本回收

输入`reclaim_samples.csv`列：sample_id（样本业务键，文本保形）、feature_version（特征版本，多版本共表）、principal（模型主体）、resource、partition（YYYY-MM）、sample_time（样本采集时刻，须带UTC偏移）、model_use（训练/评估等用途）。解析沿用访问采信约定：utf-8-sig/gb18030回退、引号换行、列数不匹配隔离、同键冲突隔离、完全相同行计重复。

授权登记（RECLAIM_GRANTS）每条含主体、资源、生效窗、分区窗和allow/deny，全部条件同时匹配，区间统一[start,end)，到期时刻立即失效。样本先按采集时刻复算覆盖授权；裁决时刻（默认2026-11-21，可由parameters.as_of覆盖）仍有效的授权才支撑继续使用。处置：有效deny命中→必须撤回（DENY_ACTIVE，拒绝优先）；有效allow命中→可继续使用（ALLOW_VALID）；仅有到期授权→必须撤回（ALLOW_EXPIRED）；无授权覆盖→必须撤回（NO_GRANT）。

每个feature_version形成唯一回收单（order_id由版本名派生，重试不变）。单内同时列出必须撤回样本、可继续使用样本及逐授权依据（grant_id、效力、裁决时刻状态、生效窗、分区窗）。裁决：存在可继续使用样本→按样本回收；全部必须撤回→整套版本撤回。回收单指纹覆盖全部裁决内容，同指纹重试幂等不新增单据；结论变化按版本条件更新，旧版与原授权依据写入history且不覆盖，冲突返回409。证据导出来自已落库回收单，撤回/保留清单与ruling跟随同一结论。
